🔋 Voltage Regulator PCB

A compact voltage regulator PCB designed to convert a higher DC input voltage into a stable regulated DC output. This project focuses on schematic design, component selection, PCB placement, and routing using KiCad.

⚙️ Features

- Stable regulated DC output
- Input and output filtering
- LED power indicator
- Compact PCB design
- Proper power and ground routing

🔧 Main Components

- Voltage regulator IC
- Input capacitor
- Output capacitor
- LED
- Current-limiting resistor
- Input/Output connectors

🛠️ Design Process

1. Designed the schematic in KiCad
2. Selected and assigned footprints
3. Created the PCB layout
4. Placed components
5. Routed power and ground connections
6. Completed PCB layout and DRC checks

🎯 Learning Outcomes

- Voltage regulator circuit design
- Power PCB layout
- Component placement
- Power and ground routing
- KiCad schematic-to-PCB workflow

🛠️ Tools Used

KiCad | PCB Design | Electronics
