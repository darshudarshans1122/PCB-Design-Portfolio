# ESP32 Development Board PCB

## 📌 Overview

This project is a custom PCB design based on the ESP32-WROOM-32 module.
The board provides easy access to ESP32 GPIO pins and includes USB connectivity,
power regulation, and programming/reset controls.

## 🔧 Features

- ESP32-WROOM-32 module
- 32 GPIO pins (16 pins on each side)
- USB interface for programming and power
- 3.3V voltage regulation
- EN/Reset button
- BOOT button
- Status/Power LED
- GPIO breakout headers
- Decoupling capacitors for stable operation

## 🛠️ Tools Used

- KiCad
- Schematic Capture
- PCB Layout
- 3D Viewer

## 📐 PCB Design

- PCB designed using KiCad
- Two-layer PCB
- Through-hole pin headers for GPIO access
- Ground plane implemented for improved signal integrity and power distribution

- ESP32 schematic design

- Two-layer PCB routing
- Ground plane/pour implementation
- Design Rule Checking (DRC)
- PCB layout and component placement
